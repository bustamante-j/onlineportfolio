# Deployed website screenshots

The homepage website cards use these filenames:

- `inkpoint-web.png`
- `edunexus.png`
- `brainbolt.png`
- `prolance.png`

To update a preview, replace the corresponding image and keep its filename. Landscape screenshots work best. Capture only the website, without browser tabs or private information; the card keeps the top of each screenshot visible on every screen size.
