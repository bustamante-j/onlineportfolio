# Replacement tool logos

These six PNG logos are connected to the homepage using these filenames:

- `skipify.png`
- `meta-business-suite.png`
- `capcut.png`
- `claude.png`
- `google-workspace.png`
- `zoom.png`

When replacing them later, keep the same filenames. Transparent-background PNG files with the logo centered and a small, even margin work best.
