# Social media portfolio uploads

Place exported post images in the matching brand folder. Use JPG, PNG, or WebP files and keep each image under 5 MB where possible.

Upload each brand's screenshots to its matching folder:

`images/social-media/rm-tiles-center/`

`images/social-media/ja-tiles-trading/`

`images/social-media/inkpoint-prints-services/`

Simple sequential filenames are recommended:

- `01.jpg`
- `02.jpg`
- `03.jpg`
- `04.jpg`
- `05.jpg`

The number controls the order in each side-scrolling gallery.
