# Homepage reels

Add up to six MP4 reels using these exact filenames:

- `reel-01.mp4`
- `reel-02.mp4`
- `reel-03.mp4`
- `reel-04.mp4`
- `reel-05.mp4`
- `reel-06.mp4`

Recommended export: 1080 × 1920, MP4 (H.264 video with AAC audio). The homepage detects these files automatically after the site is rebuilt.
