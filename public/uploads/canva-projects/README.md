# My Canva projects

Add the first two project images using these exact filenames:

- `canva-project-01.png`
- `canva-project-02.png`

The homepage is already prepared for up to eight images. Add future work sequentially as:

- `canva-project-03.png`
- `canva-project-04.png`
- `canva-project-05.png`
- `canva-project-06.png`
- `canva-project-07.png`
- `canva-project-08.png`

Use PNG files. Portrait, square, and landscape designs are supported. Only files that exist will appear on the homepage. Optimized AVIF and WebP previews are generated automatically when you run `npm run dev` or `npm run build`; the original PNG remains available in the full-resolution viewer.
